# 🎓 Student Marks Prediction

A simple supervised-learning regression project that predicts student marks from study-related data.

## What it demonstrates

- Dataset inspection
- Missing-value handling
- Feature/target separation
- Train/test splitting
- Linear Regression
- Model prediction
- Evaluation using regression metrics

## Workflow

```text
Data → Cleaning → Train/Test Split → Linear Regression → Prediction → Evaluation
```

## Technology

Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Jupyter Notebook.

This project is retained as a foundational ML example showing the complete regression workflow in a compact, easy-to-understand form.
