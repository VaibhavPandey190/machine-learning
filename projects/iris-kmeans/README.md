# 🌸 Iris K-Means Clustering

An unsupervised-learning project demonstrating K-Means clustering using the classic Iris dataset.

## What it demonstrates

- Unsupervised learning fundamentals
- Feature selection and preparation
- K-Means clustering
- Cluster interpretation
- Visualization of grouped observations

## Workflow

```text
Iris Data → Feature Preparation → K-Means → Cluster Assignment → Visualization
```

## Technology

Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Jupyter Notebook.

This project complements the regression examples in the portfolio by demonstrating an unsupervised-learning workflow.
