# 🏠 House Price Prediction

A practical supervised-learning project focused on predicting house prices from property-related features.

## Objective

Build a regression workflow that takes property information, prepares the data, trains a machine-learning model, evaluates the result, and supports price prediction.

## Workflow

```text
Raw Data
   ↓
Data Cleaning & Preprocessing
   ↓
Feature Analysis
   ↓
Train/Test Split
   ↓
Model Training
   ↓
Evaluation
   ↓
Prediction
   ↓
Model Persistence
```

## Technology

- Python
- Pandas / NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
- Pickle / JSON model metadata
